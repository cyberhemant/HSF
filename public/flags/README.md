# Flags

4:3 SVG flags from [lipis/flag-icons](https://github.com/lipis/flag-icons) (MIT, see
`LICENSE-flag-icons.txt`), one file per ISO 3166-1 alpha-2 code in lower case. They cover every
country `libphonenumber-js` knows except `AC` (Ascension) and `TA` (Tristan da Cunha), which have
no flag file. Used by the Phone Number and Autocomplete country examples; loaded lazily.
